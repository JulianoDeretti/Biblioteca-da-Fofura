# Biblioteca da Fofura 💗📚

A Biblioteca da Fofura é uma biblioteca digital pessoal criada para organizar livros já lidos, livros que ainda serão lidos e toda a coleção literária em um único lugar.

O projeto possui uma interface rosa, delicada e temática, combinando recursos de organização de biblioteca com uma experiência visual personalizada.

### Principais recursos

- Cadastro de livros;
- Livros já lidos;
- Lista de livros que deseja ler;
- Livros em leitura;
- Sistema de favoritos;
- Coleção completa;
- Pesquisa por livros e autores;
- Filtro por categorias;
- Página de autores;
- Visualização de todos os livros de um autor;
- Informações detalhadas dos livros;
- Notas e avaliações;
- Capas dos livros;
- Sinopse e observações pessoais;
- Estatísticas da biblioteca;
- Persistência dos livros cadastrados;
- Interface responsiva para computador e celular.

### Objetivo

Criar um espaço pessoal e organizado para guardar todas as histórias que fazem parte da biblioteca, permitindo acompanhar leituras e descobrir facilmente os livros e autores cadastrados.

### Identidade

O projeto utiliza uma estética baseada em tons de rosa, elementos relacionados à leitura, corações, flores e outros detalhes delicados.

> Projeto desenvolvido como uma biblioteca pessoal digital.
